# Apps papkasi

Bu papkada loyiha business logic'i modul-modul ko'rinishda joylashgan.

## App'lar tavsifi

### `users`

- registratsiya
- login/logout
- profil ma'lumotlari
- account delete
- password change

### `movies`

- movie modeli
- katalog va detail sahifalari
- filter/sort/qidiruv
- TMDB metadata enrichment
- trailer va full video media logikasi

### `interactions`

- rating
- review
- favorite
- watch history
- comment
- comment like

### `recommendations`

- recommendation service
- runtime dataframe
- popularity/content/item/svd/hybrid/auto modellar
- explainability
- recommendation lab
